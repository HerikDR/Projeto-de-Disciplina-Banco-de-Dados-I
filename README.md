
# Projeto de Banco de Dados: Plataforma de Simulados

## 📋 Descrição do Sistema
O Sistema de Simulados é uma plataforma educacional projetada para auxiliar estudantes na preparação para exames através da realização de simulados personalizados. O sistema oferece um banco de questões organizado por matérias e cursos, permitindo que os usuários testem seus conhecimentos e acompanhem sua evolução através de relatórios detalhados de desempenho.

### Características Principais:

- Banco de Questões Pré-cadastradas: Base de dados completa com questões de múltipla escolha (A-E) organizadas por matéria;
- Simulados Equilibrados: Cada simulado conterá questões distribuídas igualmente entre todas as matérias disponíveis;
- Análise de Desempenho: Métricas detalhadas por matéria, curso e histórico de evolução.


## ✔️ Funcionalidades

#### 1. Acesso ao Sistema
O usuário ao acessar a plataforma, poderá visualizar o dashboard principal, contendo todas as informações e funcionalidades desejadas;

#### 2. Iniciar Simulado
Sistema seleciona automaticamente as questões
Distribuição equitativa entre as matérias cadastradas (ex: 6 matérias = 10 questões cada), a ordem das questões é randomizada;

#### 3. Realização do Simulado
Usuário responde questão por questão, até o término da avaliação. Os resultados serão exibidos apenas no final;

#### 4. Finalização e Correção
Sistema compara respostas fornecidas com gabarito, além de gerar estatísticas imediatas e armazenar dados para histórico;

#### 5. Visualização de Resultados
Relatórios detalhados por matéria, gráficos de evolução tempora e identificação de pontos fortes e fracos.
